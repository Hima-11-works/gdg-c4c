# Frontend

React + TypeScript + Vite. See the [root README](../README.md) for setup.

```bash
npm ci             # install exact versions from package-lock.json
npm run dev        # http://localhost:5173
npm run build      # type-check + production build
npm run lint       # oxlint
npm run format     # prettier
```

Configuration: copy `.env.example` to `.env` and set `VITE_API_BASE_URL`.
